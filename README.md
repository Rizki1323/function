# Project Function Sederhana Dart

## Deskripsi
Project ini dibuat untuk mempelajari dasar Function pada bahasa Dart.

Terdapat 3 topik utama:
1. Menyapa
2. Kalkulator Luas Persegi
3. Kalkulator Diskon

Setiap topik memiliki 4 jenis function:
- Function without parameter & without return
- Function without parameter & with return
- Function with parameter & without return
- Function with parameter & with return

 Project Function Sederhana Python

## Deskripsi Project

Project ini dibuat untuk mempelajari dasar penggunaan function pada Python.
Di dalam project terdapat 3 topik utama:

1. Menyapa
2. Kalkulator Luas Persegi
3. Kalkulator Diskon

Setiap topik memiliki 4 jenis function berdasarkan tipe function yang dipelajari.

---

## Jenis Function yang Digunakan

### 1. Function Without Parameter & Without Return
Function tidak menerima parameter dan tidak mengembalikan nilai.
Biasanya langsung menampilkan output menggunakan print().

Contoh:
def halo():
    print("Halo Dunia")

### 2. Function Without Parameter & With Return

Function tidak menerima parameter tetapi mengembalikan nilai menggunakan return.

Contoh:
def angka_default():
    return 10

### 3. Function With Parameter & Without Return

Function menerima parameter tetapi hanya menampilkan hasil.

Contoh:
def sapa(nama):
    print(f"Halo {nama}")
